## ♿ Accessibility

Accessibility is an important requirement of this project.

The website includes:

- Semantic HTML5 elements
- Proper heading hierarchy
- Keyboard navigation
- Visible focus states
- Skip-to-content link
- Accessible navigation
- Proper form labels
- Required form fields
- ARIA attributes where appropriate
- `aria-current` for the active page
- `aria-describedby` for form instructions
- Responsive design
- Reduced-motion support

The website is being developed with **WCAG accessibility principles** in mind.
