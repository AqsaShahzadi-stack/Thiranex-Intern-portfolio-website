## Project Objective

The main objective of this project is to create a professional personal portfolio using a clean and semantic HTML5 structure.

The HTML implementation focuses on:

* Semantic HTML5
* Web accessibility
* Screen-reader-friendly structure
* Keyboard navigation
* SEO-friendly metadata
* Proper heading hierarchy
* Accessible navigation
* Accessible forms
* Multi-page website structure
